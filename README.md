# curator-keeper

The main loop of an agent system (working name: Keeper). On one machine it keeps the registry of the processes that machine runs — a family calendar, a café, a hobby project — routes each request a person makes to the right process, starts and supervises each process's root orchestrator, and talks with the person.

## Status

Repository created on 2026-09-24. The specification is drafted on a branch and is not normative yet.

The ecosystem map, decisions and open questions live in the private wiki (`relux-works/wiki`).
